# 레슨 02 데이터셋

이 폴더의 데이터는 NumPy 다차원 배열, 브로드캐스팅, 난수 시뮬레이션을 설명하기 위해 만든 교육용 합성 데이터다. 실제 학생, 센서, 주식 종목 정보가 아니며 개인정보가 없다. 라이선스는 CC0 로 둔다.

## 파일 목록

| 파일 | 행 수 | 컬럼 | 용도 |
|---|---:|---|---|
| `student_scores_2d.csv` | 120 | `class_id`, `student_id`, `math`, `english`, `science` | 2D 배열 슬라이싱, `axis=0/1` 집계, 과목별 표준화 |
| `dice_rolls.csv` | 4,000 | `roll_num`, `die1`, `die2`, `total` | 두 주사위 합 분포와 대수의 법칙 확인 |
| `stock_prices.csv` | 252 | `day`, `TechA`, `FinB`, `SmallC`, `MidD`, `LargeE` | 2D 시계열 배열, 로그수익률, 변동성, 랜덤워크 분석 |
| `sensor_grid.csv` | 600 | `row_idx`, `col_idx`, `temperature_c` | `reshape(20, 30)` 과 행/열 방향 최댓값 탐색 보너스 |

## 분포 의도

- `student_scores_2d.csv`: 3개 반, 반당 40명 구조다. 3반의 수학 평균이 조금 높고, 영어와 과학은 반 차이가 작도록 만들었다. 브로드캐스팅으로 과목별 평균을 빼면 각 학생의 과목별 편차가 자연스럽게 드러난다.
- `dice_rolls.csv`: 두 주사위 합이 7 근처에서 가장 많이 나오도록 균등 난수로 생성했다. 행 수는 CSV 50KB 기준을 넘지 않도록 4,000회로 제한했고, 더 큰 반복 실험은 노트북 코드에서 직접 시뮬레이션한다.
- `stock_prices.csv`: 252 영업일 동안 5개 가상 종목이 서로 다른 평균 수익률과 변동성을 갖도록 만든 랜덤워크다. `SmallC` 는 변동성이 크고, `LargeE` 는 상대적으로 안정적인 흐름을 보이도록 설계했다.
- `sensor_grid.csv`: 20×30 격자 온도 데이터다. 가운데와 오른쪽 아래 영역이 더 따뜻하고 가장자리는 낮도록 경사를 넣었다. 학생이 `reshape` 후 축 방향 최댓값을 찾기 좋다.

## 생성 방식

난수 시드는 20260517 을 기준으로 한다. 학생 점수는 정규분포를 반별 평균에 맞춰 생성한 뒤 0~100 범위로 `clip` 했다. 주사위는 정수 균등분포, 주가는 일간 로그수익률 누적합, 센서는 행·열 위치에 따른 기울기와 작은 정규 잡음으로 만들었다.

## 컬럼 규칙

- 모든 컬럼명은 영어 snake_case 또는 가상 종목명이다.
- `day` 와 `roll_num` 은 1부터 시작한다.
- 주가 단위는 원화처럼 보이지만 실제 시장 가격이 아니다.
- 결측치는 없다. 결측치와 이상치 처리는 05번 레슨에서 별도로 다룬다.
