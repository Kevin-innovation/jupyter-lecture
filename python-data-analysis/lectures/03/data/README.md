# 레슨 03 데이터셋

이 폴더의 데이터는 pandas `Series` 와 `DataFrame` 기초 실습을 위한 교육용 합성 주문 데이터다. 실제 회사, 고객, 주문 내역이 아니며 개인정보가 없다. 라이선스는 CC0 로 둔다.

## 파일 목록

| 파일 | 행 수 | 컬럼 | 용도 |
|---|---:|---|---|
| `sales_orders.csv` | 1,000 | `order_id`, `date`, `region`, `channel`, `category`, `quantity`, `unit_price`, `discount_rate`, `customer_grade` | pandas 첫 점검, 열/행 선택, 조건 필터, 계산 열, 분포 요약 |

## 코드표

- `region`: N=북부, S=남부, E=동부, W=서부, C=중앙
- `channel`: W=웹, A=앱, S=매장
- `category`: BK=도서, GD=기기, FD=식품, ST=문구, TY=완구
- `customer_grade`: N=신규, R=일반, V=VIP

## 생성 의도

데이터 크기는 1,000행이지만 CSV 50KB 기준을 지키기 위해 지역, 채널, 카테고리를 짧은 코드로 저장했다. 상품군별 단가 기준을 다르게 두어 `net_revenue` 상위 주문을 볼 때 고가 상품과 수량의 영향이 함께 나타나도록 설계했다. 웹과 앱 채널 비중이 매장보다 높고, 신규/일반 고객이 VIP보다 많다.

## 생성 방식

난수 시드 20260517 을 사용했다. 주문일은 2025년 1~6월 범위에서 생성했고, 수량은 1~5개 중 1~2개가 자주 나오도록 가중치를 주었다. 단가는 상품군 기준 가격에 정규 잡음을 더한 뒤 100원 단위로 반올림했다. 할인율은 0, 5%, 10%, 15%, 20% 중에서 선택했다.

## 결측치

이 레슨은 pandas 구조 이해가 목표라 결측치를 넣지 않았다. 결측치, 중복, 이상치 처리는 05번 레슨에서 다룬다.
