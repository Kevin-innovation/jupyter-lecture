# 레슨 08 데이터셋

이 폴더의 데이터는 `시각화 기초: matplotlib · seaborn` 수업을 위한 교육용 합성 데이터다. 실제 개인, 회사, 공공기관 정보를 포함하지 않으며 CC0 로 자유롭게 사용할 수 있다.

## 파일 목록

- `visual_insights.csv`

## 생성 의도

차트 종류별로 볼 패턴이 다르게 나타나도록 주문, 매출, 광고비, 전환율을 함께 넣었다.

## 생성 방식

난수 시드는 20260525 계열을 사용했다. 값의 범위는 초중급 학생이 출력 결과를 눈으로 확인할 수 있도록 과도하게 크지 않게 잡았다. 컬럼명은 모두 영어 snake_case 를 사용했고, 헤더 행을 포함했다.

## 결측치와 이상치

05강 데이터에는 의도적인 결측치와 이상치가 있다. 다른 레슨 데이터는 해당 강의 핵심 개념을 방해하지 않도록 결측치를 넣지 않았다.
