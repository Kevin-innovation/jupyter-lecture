# 레슨 09 데이터셋

이 폴더의 데이터는 `시계열 분석: datetime · resample · rolling` 수업을 위한 교육용 합성 데이터다. 실제 개인, 회사, 공공기관 정보를 포함하지 않으며 CC0 로 자유롭게 사용할 수 있다.

## 파일 목록

- `daily_metrics_2025.csv`

## 생성 의도

365일 데이터에 주중/주말 패턴, 성장 추세, 계절성을 약하게 섞었다. 이동평균과 월별 리샘플 효과가 보이도록 설계했다.

## 생성 방식

난수 시드는 20260526 계열을 사용했다. 값의 범위는 초중급 학생이 출력 결과를 눈으로 확인할 수 있도록 과도하게 크지 않게 잡았다. 컬럼명은 모두 영어 snake_case 를 사용했고, 헤더 행을 포함했다.

## 결측치와 이상치

05강 데이터에는 의도적인 결측치와 이상치가 있다. 다른 레슨 데이터는 해당 강의 핵심 개념을 방해하지 않도록 결측치를 넣지 않았다.
