# 레슨 07 데이터셋

이 폴더의 데이터는 `그룹화 · 집계 · 피벗` 수업을 위한 교육용 합성 데이터다. 실제 개인, 회사, 공공기관 정보를 포함하지 않으며 CC0 로 자유롭게 사용할 수 있다.

## 파일 목록

- `sales_log.csv`, `user_activity_log.csv`

## 생성 의도

매출 로그와 활동 로그는 서로 다른 grain 을 가진다. 학생이 집계 단위를 먼저 확인하도록 의도했다.

## 생성 방식

난수 시드는 20260524 계열을 사용했다. 값의 범위는 초중급 학생이 출력 결과를 눈으로 확인할 수 있도록 과도하게 크지 않게 잡았다. 컬럼명은 모두 영어 snake_case 를 사용했고, 헤더 행을 포함했다.

## 결측치와 이상치

05강 데이터에는 의도적인 결측치와 이상치가 있다. 다른 레슨 데이터는 해당 강의 핵심 개념을 방해하지 않도록 결측치를 넣지 않았다.

## 품질 보강 노트

- `그룹화 · 집계 · 피벗` 에서는 빠른 정답보다 기준을 말할 수 있는 코드가 중요하다. 중간 표가 무엇을 의미하는지 한 문장으로 설명하지 못하면, 다음 셀로 넘어가기 전에 변수명과 출력 라벨을 고친다.
