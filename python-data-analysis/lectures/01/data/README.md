# 레슨 01 데이터셋

이 폴더의 모든 데이터는 교육용 합성 데이터다. 실제 측정/수집 데이터가 아니다. 누구의 개인정보도 들어 있지 않다. 자유 사용(CC0).

## 파일 목록

| 파일 | 행 수 | 컬럼 | 단위 | 분포 특성 |
|---|---:|---|---|---|
| `scores.csv` | 200 | `score` | 점 (0~100) | 평균 ≈ 75, 표준편차 ≈ 12. 양 끝에 100점/30점대가 일부러 섞임 |
| `daily_steps.csv` | 90 | `day`, `steps` | 일자, 보 | 평일 7,800~11,500 / 주말 3,500~7,200. 가끔 극단값 1~2건 |
| `temperatures.csv` | 90 | `day`, `temperature_c` | 일자, ℃ | 봄→여름 2℃ → 18℃ 점진 상승. 한파(콜드스냅) 3일 포함 |
| `product_prices.csv` | 100 | `price` | 원 | 9천원~28천원에 75% 집중, 4만~9만원 고가 상품 10% (로그 정규에 가까운 비대칭 분포) |

## 분포 의도

각 데이터는 실습 미션에서 의도된 학습 효과를 노리고 만들어졌다.

- **scores.csv**: 정규분포에 가깝되 100점/30점대를 일부러 섞어 평균과 중앙값의 차이를 작게 만들었다. 평균 ≈ 중앙값.
- **daily_steps.csv**: 주말/평일 패턴을 넣어 boolean indexing 의 효용을 보이기 좋다. 2,100보 같은 극단값도 1~2건 있어 `min`/`argmin` 결과가 흥미롭다.
- **temperatures.csv**: 시간에 따른 상승 추세 + 노이즈로 향후 시계열 레슨(09번)에서도 재활용 가능하다. 1번 레슨에서는 단순 통계만 다룬다.
- **product_prices.csv**: 평균과 중앙값이 의도적으로 다르다(평균이 중앙값보다 큼). "평균이 끌려간다" 를 체감할 수 있는 데이터.

## 생성 방식

코스 폴더의 `lectures/01/data/_generate.py`(미포함) 에서 시드 42 의 `random` 모듈로 생성. 동일 결과를 다시 만들고 싶다면 다음 의사코드 참고:

```python
random.seed(42)
# scores: 200개 정수, 손으로 골고루 채운 다음 마지막 50개에 극단값 섞기
# steps : day 1~90, 평일=randint(7800,11500), 주말=randint(3500,7200), 5% 확률 극단값
# temp  : day 1~90, season = 2 + (d-1)*16/89, noise ±2.5℃, 콜드스냅(8/9/26일) -5℃
# prices: 100개, 85% 는 7,500~28,000원, 10% 는 45,000~89,000원, 5% 는 28,000~45,000원
```

## 컬럼명 규칙

- 영어 snake_case.
- `day` 는 1-based(1부터 시작). 실제 날짜는 아니고 "관측 시작 후 N일째" 의 의미.
- `temperature_c` 의 `_c` 는 단위(섭씨).
- `score`, `price` 는 단위 없음(점, 원). 단위는 컬럼 설명에서 명시.

## 결측치

이 레슨 데이터에는 결측치(빈 셀, NA) 가 없다. 결측치 처리는 05번 레슨(데이터 정제)에서 다룬다.
