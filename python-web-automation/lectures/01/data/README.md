# 레슨 01 데이터

이 폴더의 파일은 모두 파이썬 웹 자동화 1강을 위한 합성 데이터다. 실존 쇼핑몰, 공지사항, 개인정보를 포함하지 않는다.

| 파일 | 용도 |
|---|---|
| mini_shop.html | 상품 카드 24개가 들어 있는 정적 HTML. class selector, attribute, 가격/재고 정리 연습용 |
| notices.html | 공지 18개가 들어 있는 정적 HTML. 목록 파싱, 부서별 필터, 조회수 정렬 연습용 |
| targets.csv | 수집 대상과 허용 여부를 정리한 CSV. robots/대상 확인 습관 연습용 |
| robots_sample.txt | robots.txt 형식 예시. 실제 접근 제어 파일이 아니라 수업용 샘플 |

생성 방식: 고정 배열과 규칙 기반 숫자로 만든 합성 데이터. 외부 요청 없이 로컬/코랩에서 안정적으로 실행된다.

## 설계 의도

- `mini_shop.html` 은 카드 반복 구조를 익히기 위한 파일이다. 상품명, 카테고리, 가격, 평점, 재고, 상세 링크가 같은 패턴으로 반복된다.
- `notices.html` 은 게시판 목록 구조를 익히기 위한 파일이다. 날짜, 제목, 부서, 조회수를 추출하고 조건 필터와 정렬을 연습한다.
- `targets.csv` 는 실제 자동화 전에 대상 목록과 허용 여부를 점검하는 습관을 만들기 위한 파일이다.
- `robots_sample.txt` 는 실제 접근 제어가 아니라 수업 중 robots.txt 개념을 설명하기 위한 샘플이다.

모든 값은 교육용 합성 데이터이며 실존 개인, 회사 내부 자료, 실제 주문 정보와 관련이 없다.
